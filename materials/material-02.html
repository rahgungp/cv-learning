Image Processing & Color Spaces

Teknik pengolahan citra dasar: resizing, normalisasi, konversi warna, histogram, dan augmentasi data.

💻 Ke Praktikum →

1. Operasi Dasar Image Processing

Sebelum data gambar masuk ke model, perlu melalui tahap preprocessing — serangkaian transformasi untuk memastikan input konsisten dan berkualitas baik.

Resize & Crop

Model deep learning membutuhkan input berukuran tetap. Resize mengubah dimensi gambar; crop memotong bagian tertentu.

Python (OpenCV)
import cv2

img = cv2.imread("foto.jpg")           # BGR format (bukan RGB!)
print(f"Original: {img.shape}")        # (H, W, 3)

# Resize ke 224x224 (ukuran input ImageNet)
resized = cv2.resize(img, (224, 224))
print(f"Resized : {resized.shape}")    # (224, 224, 3)

# Center crop: potong 200x200 dari tengah
h, w = img.shape[:2]
y1 = (h - 200) // 2
x1 = (w - 200) // 2
cropped = img[y1:y1+200, x1:x1+200]

Normalisasi

Nilai piksel 0–255 diubah ke rentang 0.0–1.0 (atau −1 hingga 1) agar training lebih stabil.

Python (NumPy)
import numpy as np

img_float = img.astype(np.float32)

# Normalisasi [0, 1]
img_norm = img_float / 255.0

# Normalisasi ImageNet (mean subtraction per channel)
mean = np.array([0.485, 0.456, 0.406])
std  = np.array([0.229, 0.224, 0.225])
img_imagenet = (img_norm - mean) / std

print(f"Min: {img_imagenet.min():.2f}, Max: {img_imagenet.max():.2f}")

2. Color Spaces (Ruang Warna)

Berbeda dari RGB, ada beberapa representasi warna lain yang lebih berguna untuk task tertentu:

Color SpaceKomponenKegunaan Utama
RGBRed, Green, BlueTampilan layar, format gambar standar
BGRBlue, Green, RedDefault OpenCV (perhatikan urutan!)
GrayscaleIntensitas (1 channel)Dokumen, edge detection, reduksi kompleksitas
HSVHue, Saturation, ValueSegmentasi berdasarkan warna (deteksi bola merah, dll)
LABLuminance, a, bPerceptually uniform — cocok untuk transfer warna
YCrCbLuma, Chroma R, Chroma BKompresi video, deteksi kulit
Python
import cv2
import numpy as np

img_bgr = cv2.imread("foto.jpg")

# BGR → RGB (untuk matplotlib)
img_rgb = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2RGB)

# BGR → Grayscale
img_gray = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2GRAY)
print(f"Gray shape: {img_gray.shape}")   # (H, W) — 2D saja

# BGR → HSV (untuk segmentasi warna)
img_hsv = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2HSV)

# Deteksi warna merah dalam HSV
lower_red = np.array([0, 100, 100])
upper_red = np.array([10, 255, 255])
mask = cv2.inRange(img_hsv, lower_red, upper_red)
result = cv2.bitwise_and(img_bgr, img_bgr, mask=mask)

3. Histogram Gambar

Histogram menunjukkan distribusi nilai piksel. Berguna untuk menilai kecerahan, kontras, dan sebaran warna gambar.

💡 Kapan Gunakan Histogram?
Analisis kualitas gambar, histogram equalization untuk meningkatkan kontras, dan thresholding otomatis (Otsu's method).
Python
import cv2
import matplotlib.pyplot as plt

img = cv2.imread("foto.jpg")
img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)

# Plot histogram untuk setiap channel
fig, axes = plt.subplots(1, 2, figsize=(12, 4))

# Tampilkan gambar
axes[0].imshow(img_rgb)
axes[0].set_title("Gambar Asli")
axes[0].axis('off')

# Histogram
colors = ('r', 'g', 'b')
for color in colors:
    channel = {'r': 0, 'g': 1, 'b': 2}[color]
    hist = cv2.calcHist([img], [channel], None, [256], [0, 256])
    axes[1].plot(hist, color=color)
axes[1].set_title("Histogram RGB")
axes[1].set_xlabel("Nilai Piksel (0-255)")
axes[1].set_ylabel("Jumlah Piksel")

plt.tight_layout()
plt.show()

# Histogram Equalization (meningkatkan kontras)
img_gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
img_eq = cv2.equalizeHist(img_gray)

4. Data Augmentation

Augmentasi memperbanyak data training dengan menerapkan transformasi acak — meningkatkan generalisasi model.

↔️

Flip

Cermin horizontal/vertikal. Berguna untuk gambar yang simetris.

🔄

Rotate

Rotasi ±15–30°. Membuat model tahan terhadap orientasi berbeda.

🔆

Brightness/Contrast

Variasi pencahayaan agar robust terhadap kondisi cahaya berbeda.

🌫️

Blur/Noise

Simulasi kamera low-quality atau gerakan. Meningkatkan ketahanan.

✂️

Random Crop

Potong bagian acak — model belajar dari berbagai perspektif.

🎨

Color Jitter

Variasi hue, saturasi, brightness secara acak.

Python (PyTorch torchvision)
from torchvision import transforms

# Pipeline augmentasi untuk training
train_transform = transforms.Compose([
    transforms.RandomResizedCrop(224),         # Random crop + resize
    transforms.RandomHorizontalFlip(p=0.5),    # Flip horizontal 50%
    transforms.ColorJitter(
        brightness=0.2, contrast=0.2,
        saturation=0.2, hue=0.1
    ),
    transforms.RandomRotation(15),             # Rotasi ±15°
    transforms.ToTensor(),                     # PIL → Tensor [0,1]
    transforms.Normalize(
        mean=[0.485, 0.456, 0.406],
        std=[0.229, 0.224, 0.225]
    )
])

# Pipeline untuk validasi (tanpa augmentasi acak)
val_transform = transforms.Compose([
    transforms.Resize(256),
    transforms.CenterCrop(224),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406],
                         std=[0.229, 0.224, 0.225])
])

📌 Rangkuman Materi 02

  • Preprocessing wajib sebelum data masuk model: resize, normalisasi, konversi warna.
  • OpenCV default menggunakan format BGR, bukan RGB. Selalu konversi saat menampilkan!
  • HSV berguna untuk segmentasi berbasis warna; LAB untuk operasi perceptual.
  • Histogram menunjukkan distribusi piksel — gunakan equalization untuk meningkatkan kontras.
  • Augmentasi memperbanyak data training dan mencegah overfitting.
