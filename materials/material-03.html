1. Operasi Konvolusi (Convolution)

Konvolusi adalah operasi matematika yang menggeser sebuah kernel (filter kecil) di atas gambar, mengalikan nilai piksel dengan bobot kernel, lalu menjumlahkannya menjadi satu nilai output.

🔢 Formula Konvolusi 2D
(I * K)[i,j] = Σ Σ I[i+m, j+n] · K[m,n]
Di mana I = gambar input, K = kernel, m,n = indeks kernel.

Konsep Kernel (Filter)

Kernel adalah matriks kecil (biasanya 3×3 atau 5×5) yang menentukan efek konvolusi:

Identity (Tidak Berubah)

000
010
000

Menghasilkan gambar sama persis

Blur (Averaging)

111
111
111

Dibagi 9 — meratakan/mengaburkan

Sobel X (Edge Horizontal)

-101
-202
-101

Deteksi tepi vertikal (gradien X)

Sharpen (Ketajaman)

0-10
-15-1
0-10

Mempertajam detail gambar

Python (OpenCV)
import cv2
import numpy as np

img = cv2.imread("foto.jpg", cv2.IMREAD_GRAYSCALE)

# Definisi kernel manual
kernel_blur = np.ones((3,3), np.float32) / 9
kernel_sharp = np.array([[0, -1, 0], [-1, 5, -1], [0, -1, 0]], np.float32)
kernel_sobel_x = np.array([[-1, 0, 1], [-2, 0, 2], [-1, 0, 1]], np.float32)

# Terapkan konvolusi dengan filter2D
blurred  = cv2.filter2D(img, -1, kernel_blur)
sharpened = cv2.filter2D(img, -1, kernel_sharp)
edges_x   = cv2.filter2D(img, -1, kernel_sobel_x)

print(f"Output shape: {blurred.shape}")   # Sama dengan input

2. Filter Populer dalam Computer Vision

Gaussian Blur

Filter blur paling populer. Berdasarkan distribusi Gaussian — piksel tengah diberi bobot lebih besar. Digunakan untuk mengurangi noise sebelum edge detection.

Python
import cv2

img = cv2.imread("foto.jpg")

# Gaussian Blur — (kernel_size, sigmaX)
blur3  = cv2.GaussianBlur(img, (3, 3), 0)    # Ringan
blur11 = cv2.GaussianBlur(img, (11, 11), 0)  # Kuat
blur21 = cv2.GaussianBlur(img, (21, 21), 5)  # Sangat kuat

# Median Blur — cocok untuk salt-and-pepper noise
median = cv2.medianBlur(img, 5)

# Bilateral Filter — blur tapi pertahankan tepi
bilateral = cv2.bilateralFilter(img, 9, 75, 75)

Edge Detection: Canny Algorithm

Canny adalah algoritma deteksi tepi multi-stage yang paling banyak digunakan. Terdiri dari: Gaussian blur → Gradient computation → Non-maximum suppression → Double thresholding → Edge tracking.

Python
import cv2
import matplotlib.pyplot as plt

img = cv2.imread("foto.jpg")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# Gaussian blur sebelum Canny (mengurangi noise)
blurred = cv2.GaussianBlur(gray, (5, 5), 0)

# Canny: (gambar, threshold_rendah, threshold_tinggi)
edges_soft = cv2.Canny(blurred, 30, 100)    # Lebih banyak tepi
edges_hard = cv2.Canny(blurred, 100, 200)   # Hanya tepi kuat

# Sobel + magnitude gradient
sobel_x = cv2.Sobel(gray, cv2.CV_64F, 1, 0, ksize=3)
sobel_y = cv2.Sobel(gray, cv2.CV_64F, 0, 1, ksize=3)
magnitude = np.sqrt(sobel_x**2 + sobel_y**2)

plt.imshow(edges_hard, cmap='gray')
plt.title('Canny Edge Detection')
plt.show()

3. Padding & Stride

Dua parameter penting dalam konvolusi yang menentukan ukuran output feature map:

ParameterDeskripsiEfek
Padding = 0 (valid) Tidak tambah piksel di tepi Output lebih kecil dari input
Padding = 1 (same) Tambah 1 baris/kolom 0 di setiap tepi Output sama ukuran input
Stride = 1 Geser kernel 1 piksel tiap langkah Output paling detail
Stride = 2 Geser kernel 2 piksel tiap langkah Output setengah ukuran (downsampling)
📐 Rumus Ukuran Output
Output = ⌊(Input - Kernel + 2×Padding) / Stride⌋ + 1
Contoh: Input=28, Kernel=3, Padding=1, Stride=1 → Output = ⌊(28-3+2)/1⌋+1 = 28

4. Hubungan Konvolusi dengan CNN

Inilah yang membuat CNN (Convolutional Neural Network) revolusioner:

🧠 Insight Kunci
Dalam konvolusi manual, kita yang menentukan kernel (blur, sharpen, dll).
Dalam CNN, jaringan yang belajar kernel terbaik untuk task melalui backpropagation!
  • Layer Conv di CNN = banyak kernel yang dipelajari secara otomatis
  • CNN layer awal belajar tepi dan warna, layer dalam belajar pola kompleks
  • Parameter sharing: kernel yang sama digeser ke seluruh gambar → efisien
  • Translation equivariance: objek di mana saja dalam gambar tetap terdeteksi

📌 Rangkuman Materi 03

  • Konvolusi = menggeser kernel di atas gambar, jumlahkan produk elemen.
  • Kernel menentukan efek: blur, sharpen, deteksi tepi, dll.
  • Filter penting: Gaussian blur (noise reduction), Canny (edge detection), Sobel (gradient).
  • Padding menjaga ukuran output; Stride mengontrol downsampling.
  • CNN = konvolusi dengan kernel yang dipelajari otomatis dari data.
