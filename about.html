Tentang COM Platform

Computer Vision Learning Platform — dibuat untuk mahasiswa Program Studi Teknik Komputer, Universitas Warmadewa.

Tentang Platform Ini

COM (Computer Vision Learning Platform) adalah platform pembelajaran Computer Vision berbasis web yang dirancang untuk mendukung perkuliahan dan pembelajaran mandiri di Program Studi Teknik Komputer, Universitas Warmadewa.

Platform ini menyediakan 16 modul materi yang mencakup topik dari pengenalan Computer Vision dasar hingga teknik lanjutan seperti Vision Transformers, GANs, Object Detection, dan Model Optimization. Setiap modul dilengkapi teori interaktif, praktikum Python (via Google Colab), dan kuis evaluasi.

Fitur Utama

▶

Presentation Mode

Mode fullscreen untuk belajar fokus. Navigasi dengan keyboard (← →, Space, Esc, Home, End) atau swipe di mobile.

📊

Progress Tracking

Progres belajar tersimpan di browser secara lokal — teori dibaca, praktikum selesai, kuis lulus.

🧠

Kuis Interaktif

5 soal per materi dengan penjelasan jawaban. Pass 60% untuk mendapatkan tanda centang.

🌙

Dark Mode

Tema terang dan gelap dengan preferensi tersimpan otomatis.

💻

Kode Siap Pakai

Copy code sekali klik. Contoh Python lengkap untuk setiap topik.

📱

Mobile Friendly

Responsif di semua ukuran layar. Sidebar menjadi drawer di mobile.
